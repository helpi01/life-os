# Life OS

Личный «пульт управления жизнью»: финансы, инвестиции, спорт, привычки, планы,
здоровье, питание и ИИ-ассистент. Веб-версия для браузера на компьютере и телефоне.

## Как запустить (Windows)

Просто дважды кликни **start.bat**. Скрипт сам поставит зависимости,
соберёт приложение и откроет браузер на http://localhost:8080.

## Как открыть на телефоне

1. Компьютер и телефон должны быть в одной Wi-Fi сети.
2. Узнай IP компьютера: `ipconfig` → строка «IPv4-адрес» (например 192.168.1.42).
3. Открой на телефоне: `http://192.168.1.42:8080`.
4. Если телефон не открывает — разреши доступ в брандмауэре Windows
   (выскочит запрос при первом обращении, либо добавь правило для порта 8080).
5. На телефоне можно «Добавить на главный экран» — будет как приложение.

## Запуск вручную

```
npm install
npm run build     # сборка в dist/index.html (один файл, всё внутри)
npm run serve     # сервер на http://0.0.0.0:8080
```

## Выгрузка на сервер / хостинг

Файл **dist/index.html** самодостаточный (весь JS и CSS внутри).
Его можно загрузить на любой статический хостинг (GitHub Pages, Netlify,
Vercel, свой сервер) — приложение заработает по ссылке.

## Разработка

```
npm run dev       # dev-сервер Vite с горячей перезагрузкой
```
